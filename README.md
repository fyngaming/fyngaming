## 🔭 Sedang fokus — NeuroCycleAI
🎯 NeuroCycleAI — platform yang menyatukan neuroscience + machine learning untuk menciptakan jalur belajar adaptif.  
NeuroCycleAI menganalisis gaya dan pola belajar pengguna lalu menyesuaikan rekomendasi materi secara real-time sehingga setiap sesi belajar terasa relevan, efisien, dan memotivasi.

Fase sekarang: 
- mengumpulkan dan membersihkan data pengguna (pipeline)  
- membangun model rekomendasi adaptif berbasis perilaku belajar  
- dashboard visual untuk guru & pelajar (insight & progress)

[➡️ Lihat repo NeuroCycleAI](https://github.com/fyngaming/NeuroCycleAI)
